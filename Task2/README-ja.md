# タスク2: 単語推測ゲーム

このタスクでは、Wordleスタイルの単語推測ゲームを実装します。このゲームでは、ユーザーが単語を推測し、フィードバックを受け取ります。

## 要件

### WordGuessingGame クラス

`WordGuessingGame` クラスは以下のメソッドを実装する必要があります：

1. `__init__(target_word)`: ターゲットワードでゲームを初期化します。
   - 引数: `target_word` (str) - 推測される単語
   - 例外: `ValueError` - ターゲットワードが5文字でない場合

2. `get_unused_letters()`: どの推測でも使用されていない文字のセットを返します。
   - 戻り値: `set` - 未使用の文字のセット

3. `guess(word)`: 推測を行い、Wordleスタイルのフィードバックを取得します。
   フィードバックは文字列のリストです：
   - "correct": 文字が正しい位置にある
   - "present": 文字は単語内にあるが、位置が間違っている
   - "absent": 文字は単語内にない
   - 引数: `word` (str) - 推測された単語
   - 戻り値: `list` - 各文字のフィードバック文字列のリスト
   - 例外: `ValueError` - 推測された単語が5文字でない場合

4. `is_solved()`: ゲームが解決されたかどうかを確認します。
   - 戻り値: `bool` - 最後の推測が正しければTrue、そうでなければFalse
